# Admin interface

`apps/web` is the internal desk for two people: an owner and a clerk. It is a Next.js app on port 3001. The browser talks only to that origin. Next.js proxies `/api/auth/*`, `/api/deals/*`, and `/api/admin/*` to the Fastify API (`API_URL`, default `http://127.0.0.1:3000`). The session cookie is `HttpOnly`, so page scripts cannot read it.

## Pages

| Path                | Who        | What is on the page                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| ------------------- | ---------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `/login`            | signed out | Username and password. Errors stay on the form. The button stays disabled while the request is in flight. Too many attempts shows the wait message.                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| `/`                 | signed in  | Sends an admin to `/admin` and everyone else to `/deals`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| `/admin`            | admin      | Counts and the review queue. Filters cover the other statuses. Anyone else receives 403: "You don't have access to this page."                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| `/admin/deals/[id]` | admin      | Two columns: the editable deal, then the post preview. Phones stack them. An approved deal can be published now or scheduled for a time in the next 7 days, shown in India time. Publish now asks for confirmation and shows the channel name. A scheduled deal shows its time, can be unscheduled, and cannot be edited until then. An uncertain post asks whether it appeared in the channel. Approve stays on the page and shows "Approved." Send back returns to the queue and shows "Sent back to <name>." once. Reject returns to the queue and shows "Rejected." once. Reopen and unapprove stay on the page. |
| `/admin/publishing` | admin      | Whether publishing is on, whether it is paused, how many posts went out today, the next scheduled time, and how many posts are uncertain. Pause, resume, and a small form for the daily limit and the minimum gap. A history table, newest first, with a status filter and paging.                                                                                                                                                                                                                                                                                                                                   |
| `/deals`            | signed in  | Two buttons: New deal and My deals.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| `/deals/new`        | signed in  | Deal form. `?id=` redirects to the edit page.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| `/deals/[id]/edit`  | signed in  | The same form, filled with that person's draft. The product link is read-only. Other deals show "You can't edit this deal".                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| `/deals/mine`       | signed in  | That person's deals, with Preview, a status badge, and the review note when a deal was sent back or rejected. Edit opens the form. A deal waiting for review is withdrawn first.                                                                                                                                                                                                                                                                                                                                                                                                                                     |

Other sessions are signed out.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |

Someone who is not signed in is sent to `/login`. The screen does not use the words owner or clerk.

## Shell

The signed-in pages share a top bar: the name SS Deals, the person's display name, Account, and Log out. An admin also sees a small Admin label. Under that, an admin sees Review queue, Publishing, and New deal. Everyone else sees New deal and My deals. Controls are large and the colours are teal `#0F766E`, amber `#F59E0B`, slate text, and an off-white background. Buttons, links, summaries, file pickers, selects, and checkbox or radio labels use a pointer cursor. Disabled controls use a not-allowed cursor.

## Images

Every deal image address includes the deal's latest update time (`?v=`). Replacing or removing an image on the review page updates that time from the server response, so the new image or the "No image" placeholder shows without a reload. The same address is used on the queue thumbnails, the review preview, and a person's own preview. While an upload is running the page says "Saving image…". A failed upload stays on the page and shows the error. The image response itself is `Cache-Control: private, no-cache`.

## Run

From the repo root, with Postgres and the API up:

```bash
pnpm dev:web
```

Open `http://localhost:3001`. Create the two accounts with the API scripts (they prompt for a password and refuse one on the command line):

```bash
pnpm --filter @ss-deals/server user:create --username OWNER --role owner --name "Full Name"
pnpm --filter @ss-deals/server user:create --username CLERK --role clerk
```

`--name` is optional. `user:set-name --username NAME --name "Full Name"` changes the name shown in the top bar. `user:set-password` and `user:deactivate` take `--username`. Changing a password from the command line, or deactivating an account, signs that person out. Changing a password from the Account page signs out the other sessions only.

Compose publishes the site on `127.0.0.1:3001`. Set `WEB_BIND` to a LAN or Tailscale address when the desk should be reachable from another machine on that network. Do not publish it on the public internet.
